# Naveen Nandasiri — Portfolio

A responsive one-page portfolio prepared for deployment on Vercel.

## Preview locally

From this folder, run:

```bash
python -m http.server 3000
```

Then open `http://localhost:3000`.

## Deploy to Vercel

1. Push this folder to a GitHub repository.
2. In Vercel, choose **Add New → Project**.
3. Import the GitHub repository.
4. Leave **Framework Preset** as `Other`.
5. Leave the build command empty and set the output directory to `.`.
6. Select **Deploy**.

## Update the CV later

Replace `assets/Naveen_Nandasiri_CV.pdf` with the updated PDF using the same filename. The download button will continue to work.

## Main content files

- `index.html` — portfolio content
- `styles.css` — visual design and responsive layout
- `script.js` — navigation, reveal animation and contact-form behavior
- `assets/` — portrait, project screenshot, CV and favicon
